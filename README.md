# Wordle
Aplicación que simula la web wordle, creado por 
#### Sendoa Perez Otaola ####

## Caracteristicas ##
- Conexion a Api para conseguir palabra aleatoria
- limite de 5 intentos

## Ejemplo Wordle ##

| Palabra | Resultado |
|-------- | ---------- |
| Sacos | VVRRA |
| Sapos | VVRRA |
| Salsa | VVVVV |
